Checkbox Component - WCAG 2.1 AA Demo

This demo tests the React Checkbox component against WCAG 2.1 AA accessibility standards and functional requirements.

Component Functional Tests
Click the checkbox or press Space when focused. Verify aria-label is "Enabled checkbox". Expected: checked state changes and aria-checked updates.
This checkbox is disabled. Verify it cannot be clicked or toggled with Space. Expected: No state change possible.
This checkbox starts in checked state. Press Space to toggle off. Expected: State changes from checked to unchecked.
Tab to this checkbox. Verify visible focus indicator (blue outline). Expected: Blue 2px outline appears on focus.
Compilation & Type Safety (AC-6)

Run tsc --noEmit to verify TypeScript compilation succeeds with zero errors.

Expected: Exit code 0, no type errors in Checkbox.tsx and Checkbox.types.ts

Styling with Tailwind CSS (AC-7)

Generated Checkbox component uses Tailwind CSS classes for styling.

Verify: className includes Tailwind utilities (e.g., "focus:outline-2", "disabled:opacity-50")

Documentation (AC-8)

README.md includes usage example: 

import { Checkbox } from './Checkbox';

export function App() {
  return (
    <Checkbox
      label="Accept terms"
      checked={false}
      onChange={(checked) => console.log(checked)}
      disabled={false}
    />
  );
}
