# OX 퀴즈 출제 및 선택 위젯

## 개요
교육용 모바일 앱에서 사용할 OX(O/X) 퀴즈 인터페이스. 사용자가 여러 문제를 보고 O 또는 X를 선택하여 답변하는 기능.

## 요구사항

### 기능 요구사항
- OX 퀴즈 문제 목록 표시 (한 번에 1문제씩)
- 사용자가 O 또는 X 버튼 중 선택
- 선택 후 정답 표시 및 설명
- 진행도 표시 (3/10 문제 완료 등)
- 다시 풀기 기능

### 비기능 요구사항
- 반응형 설계 (모바일/태블릿)
- 전환 애니메이션
- 접근성: 키보드 네비게이션 지원

### 디자인 제약
- Tailwind CSS만 사용
- 색상: 정답은 녹색, 오답은 빨간색, 중립은 회색
- 폰트: 시스템 기본 폰트

## 구조

### 컴포넌트
1. **QuizContainer** - 전체 퀴즈 레이아웃
2. **QuestionCard** - 현재 문제 표시
3. **AnswerButtons** - O/X 선택 버튼
4. **ProgressBar** - 진행도 표시
5. **ResultDisplay** - 정답/오답 피드백

### 상태
- 현재 문제 번호
- 사용자 답변
- 정답 여부
- 완료 여부
